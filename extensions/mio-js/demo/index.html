Mio lives here now

Everything on this page except Mio is one HTML file with no build step. Mio itself is a single <script> at the bottom of the document.

Things to try

Pick it up. Grab Mio and drag it around. The body squashes against whatever it is pressed into, and the eyes keep tracking the cursor the whole time.

Throw it. Flick the pointer and let go. It keeps the velocity of your hand, drifts across the page, and bounces off the edges of the viewport — those are hard walls, wherever you scroll to.

Drop it on a heading. Every h1 and h2 on this page is a collision marker (the dashed boxes). Mio is drawn toward the nearest one, lands on it, and squashes on impact. Scroll while it is resting and it rides the heading down the page.

Watch the margins. The collision rect is each heading's content box — the tinted area — so the 4rem of margin above every heading is empty air Mio falls straight through.

The whole integration

<script src="mio.min.js" data-mio-colliders="h1, h2"></script>

Drop the attribute and Mio floats in an empty room, which is what it does on an OpenStation desk with every window closed.

From script

Mio.setColliders( 'h1, h2, img' );
Mio.setPosition( 200, 300 );
Mio.stop();
await Mio.start();

document.addEventListener( 'mio:dropped', ( e ) => {
	console.log( 'put down at', e.detail.position );
} );

Another marker

Mio's physics run at a fixed 240 Hz sub-step regardless of your display's refresh rate, so a throw feels the same on a 60 Hz laptop panel and a 120 Hz phone.

And one more

The silhouette changes on its own every minute or so — circle, blob, ghost, star, heart, cloud — and eases across rather than popping, because the shape lives in the soft body's spring rest lengths rather than in a redraw. Pick Mio up mid-morph and the change carries on underneath your hand.

The last one

If you have reduce motion switched on at the OS level, Mio holds still by itself: no idle bob, no silhouette shuffle. Motion you cause — a drag, a throw, the squash on landing — stays, because a companion that refuses to move when you pick it up is broken rather than accessible.
