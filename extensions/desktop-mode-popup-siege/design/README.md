# Popup Siege evidence custody

The files in this directory and
`games/popup-breaker/docs/evidence/` were carried forward from the Popup Siege
0.7.0 OpenStation release at commit `8eb8ee3`.

The native screenshot and its approval cover the exact 1536 × 960 PNG only:
hierarchy, alignment, legibility, clipping, overlap, and target priority in one
playing state. They do not establish interaction quality, responsive behavior,
alternate states, animation, audio quality, implementation correctness, or
fun.

The generated side-console art remains the selected prototype-runtime asset.
Its source image, locally derived transparent runtime image, prompt record,
critique, dimensions, and SHA-256 hashes are retained together. Live words,
values, controls, states, collision geometry, and focus remain code-native.

The upstream evidence cohort identifies an earlier Game Lab source inventory.
The adapter, deterministic runtime, top-level stylesheet, and image assets in
this plugin are hash-pinned to that release. The new standalone WordPress
wrapper is outside the upstream cohort and is covered separately by this
plugin's registration smoke test, score-contract test, release verifier,
packaging inspection, and Plugin Check.

Fresh Human Fun Proof and a human audio-listening pass remain pending. Nothing
in these files should be read as evidence that either gate has passed.
